# 모바일·포터블 도구 안전 운영 가이드

## 기본 원칙

포터블 실행 파일과 모바일 진단 도구는 설치가 간단한 만큼 출처·무결성·데이터 잔존 위험을 더 엄격히 관리한다. 테스트 기기 또는 명시적 승인을 받은 기기만 연결한다. 잠금 해제, 루팅, 우회, 원격 제어 활성화는 별도 승인 없이는 하지 않는다.

## 준비

1. 도구의 공식 배포 페이지, 버전, 서명 또는 해시를 확인한다.
2. 승인된 이동식 저장장치 또는 암호화된 작업 폴더에만 보관한다.
3. 실행 전 Microsoft Defender 또는 조직 보안 제품의 검사 결과를 확인한다.
4. 모바일 기기에서는 개발자 옵션·USB 디버깅이 필요한지 확인하고, 필요할 때만 일시적으로 켠다.

## 실행 중 주의

- 연결 직후 화면 잠금, 알림, 사진, 연락처, 메시지 등 대상 범위를 넘어서는 데이터에 접근하지 않는다.
- 자동 백업·동기화·클라우드 업로드 옵션은 끈 상태를 기본으로 한다.
- USB 권한 승인 창의 컴퓨터 식별 정보를 확인하고, 공용 PC에서는 `항상 허용`을 선택하지 않는다.
- 수집 파일 이름에 실명, 전화번호, 기기 식별자, 사건 번호를 넣지 않는다.

## 작업 후

1. 기기에서 USB 디버깅과 해당 PC 신뢰를 해제한다.
2. 포터블 도구의 임시 폴더, 로그, 내보낸 보고서를 확인한다.
3. 필요한 산출물만 승인된 보관소로 옮기고, 나머지는 보존 정책에 맞게 처리한다.
4. 이동식 저장장치는 분리 전 안전하게 제거하고, 분실·오염 가능성이 있으면 보안 담당자에게 알린다.

프로젝트에는 실행 파일, APK, 드라이버, 기기 덤프, 모바일 백업, 디버그 로그를 추가하지 않는다.
