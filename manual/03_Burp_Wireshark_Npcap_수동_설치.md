# Burp Suite · Wireshark · Npcap 수동 설치 가이드

## 사전 승인

프록시 분석과 패킷 캡처는 타인의 통신·자격 증명·개인 정보를 수집할 수 있다. 본인이 소유하거나 서면으로 승인받은 시스템과 네트워크에서만 수행한다. 업무망에서는 보안팀의 캡처 정책, 허용 인터페이스, 저장 기간을 먼저 확인한다.

## Burp Suite

1. PortSwigger의 공식 배포본과 조직이 보유한 적법한 에디션을 확인한다.
2. 설치 중 프록시 리스너는 기본적으로 로컬 호스트에만 바인딩한다. 외부 인터페이스 공개는 별도 승인 없이는 하지 않는다.
3. 브라우저 프록시 설정은 테스트 프로필에만 적용하고, 작업 후 원래 설정으로 되돌린다.
4. HTTPS 테스트가 필요할 때만 테스트 브라우저 프로필에 Burp CA를 신뢰한다. 운영 사용자 프로필이나 시스템 전체 신뢰 저장소에 무분별하게 추가하지 않는다.
5. 프로젝트 파일과 HTTP 히스토리는 민감할 수 있다. 암호화된 승인 위치에 저장하고 저장소에 추가하지 않는다.

## Npcap

1. Wireshark Foundation의 공식 Npcap 배포본을 사용한다.
2. 설치 옵션은 필요한 캡처 호환성만 선택한다. 레거시 호환 모드는 정말 필요한 경우에만 사용한다.
3. 드라이버 설치 권한 요청과 재부팅 필요 여부를 확인한다.
4. 설치 후 Wireshark에서 인터페이스 목록이 표시되는지만 확인한다. 권한이 부족하면 관리자 권한 상시 실행 대신 조직의 승인된 권한 정책을 따른다.

## Wireshark

1. 공식 설치본의 게시자와 버전을 확인한다.
2. 시작 후 `Help > About`에서 버전을 기록하고, 테스트 인터페이스에서 짧은 캡처로 동작만 확인한다.
3. 캡처 필터는 수집 전 범위를 줄이는 데 사용하고, 표시 필터는 이미 수집된 데이터의 표시만 바꾼다는 점을 구분한다.
4. 민감 트래픽이 포함될 수 있으므로 캡처 파일은 암호화된 승인 위치에 저장하고, 공유 전 익명화한다.

## 최소 검증과 정리

테스트 종료 후 Burp 프록시 설정과 브라우저 인증서를 되돌리고, 불필요한 캡처를 보존 정책에 따라 안전하게 처리한다. `burp-settings.template.json`은 빈 구조 예시일 뿐 실제 프로젝트/사용자 설정을 대체하지 않는다.
