# 라이선스 도구 수동 설치·관리 가이드

## 허용 범위

상용 또는 라이선스 기반 도구는 구매·배포·활성화 권한이 확인된 경우에만 설치한다. 평가판 제한 우회, 키 생성, 크랙, 라이선스 파일 공유는 금지한다.

## 설치 절차

1. 자산 관리 또는 구매 담당자에게 제품명, 에디션, 좌석 수, 사용 기간, 대상 장비 승인을 확인한다.
2. 공식 공급자 포털 또는 조직의 소프트웨어 센터에서 설치 파일을 받는다.
3. 다운로드 페이지의 게시자, 코드 서명, 버전, 해시(제공된 경우)를 확인한다.
4. 설치 옵션에서 불필요한 브라우저 확장, 원격 지원, 텔레메트리, 자동 시작 항목을 검토한다.
5. 활성화는 공급자가 안내한 방식으로만 수행한다. 키·응답 파일·활성화 화면을 복사하거나 저장소에 넣지 않는다.
6. 설치 후 제품 버전, 설치 날짜, 자산 태그, 승인 티켓만 자산 기록에 남긴다.

## 오프라인·공유 장비 주의

- 오프라인 활성화 파일은 민감 자산이다. 승인된 암호화 저장소에서만 취급한다.
- 여러 사용자가 쓰는 장비에서는 개인 계정 자동 로그인을 끄고, 작업 후 로그아웃한다.
- 라이선스 서버 주소와 프록시 설정은 조직 표준을 따른다. 임의의 우회 서버를 추가하지 않는다.

## 업데이트 및 제거

업데이트 전 릴리스 노트와 호환성을 확인한다. 제거가 필요하면 사용 중인 라이선스 좌석을 먼저 반납하는지 공급자 절차를 확인하고, 진단 결과나 라이선스 파일을 지우기 전 보존 정책을 따른다.

## 점검표

- [ ] 공식 또는 승인된 출처에서 설치함
- [ ] 서명/게시자와 버전을 확인함
- [ ] 승인된 사용자·장비·기간을 확인함
- [ ] 비밀 값과 라이선스 자료가 프로젝트 밖에 보관됨
- [ ] 설치·변경 이력이 자산 관리에 기록됨
